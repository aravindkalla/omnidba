📚 Training Layer
Per-Engine Schema Seeding — train_schema(engine)
A one-time seed populates a per-engine ChromaDB store with catalog DDL and curated question–SQL pairs. Oracle and PostgreSQL keep separate stores, so the same question resolves correctly on each engine. Successful Tier-2 queries write back — a self-improving loop.
